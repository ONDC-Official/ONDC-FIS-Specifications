Offline Journey

The borrower accepts the offer and completes these steps on the lender's pages:

  1. KYC
  2. Bank account verification
  3. Repayment set-up (e-mandate or SI)
  4. Loan agreement

Some steps are done offline (for example a branch visit or a document pick-up). While the offline step is open, the lender reports form_response.status OFFLINE_PENDING.

The lender sends an unsolicited on_status after each step.
